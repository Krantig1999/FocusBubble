# 📱 FocusBubble – Smart Distraction Blocker

FocusBubble helps you stay productive by blocking distracting apps like WhatsApp, LinkedIn,facebook ,Instagram etc., using Accessibility Service.

## ✨ Features
- Block apps during focus sessions
- Motivational quote screen
- Clean, minimal UI
- Typing animation effect
